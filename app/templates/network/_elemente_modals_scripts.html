{# JS fuer die zwei Elementliste-Modals (Element bearbeiten + Wartung & Prüfung). - open*Modal(btn): laedt den jeweiligen Body per HTMX-GET (X-From-Modal) und merkt sich die Action-URL fuer den Footer-Submit. - Element bearbeiten: Footer-Submit -> POST -> 204 + HX-Trigger closeFeatureEditModal -> Modal schliessen. - Wartung: Footer-Submit „Eintrag hinzufügen" -> POST -> Body-Fragment zurueck (Modal bleibt offen, Liste/Felder aktualisiert). Schließen nur ueber den Schließen-Button. - Tabelle bei jedem Modal-Schließen mit aktuellen Filtern neu laden. base.html laedt htmx/bootstrap mit `defer`: bei hartem Reload laeuft dieses Skript VOR den Libraries. Deshalb wird nichts beim Setup abgebrochen — die Libraries werden erst im Klick/Event aufgeloest. Das Skript laeuft bei jedem hx-boost-Swap erneut: Element-Listener gehen an die frischen Elemente, document-Listener nur einmal. #}
